# Plan de travail

## Description générale

Le plan de travail présente de manière concise et structurée la nature du projet, le problème à résoudre ainsi que l’approche proposée pour y répondre.

Il débute par une **introduction** exposant le contexte et décrivant clairement le problème. Il précise ensuite les **objectifs du projet** et détaille l’**approche scientifique** retenue pour atteindre ces objectifs.

## Contenu du plan

Le document comprend :

- Une description des **étapes du projet**
- La **répartition des tâches** entre les membres de l’équipe
- Les éléments clés suivants :
  - Recherches bibliographiques  
  - Analyse théorique  
  - Définition des critères de conception  
  - Étude des solutions possibles  
  - Expérimentation proposée  
  - Construction d’un prototype  
  - Considérations humaines, éthiques, juridiques et de gestion  

## Planification

Le plan inclut également :

- Un **calendrier d’exécution** présenté sous forme graphique  
- Un **tableau chronologique** indiquant la durée prévue pour chaque tâche  
- La **méthodologie utilisée**  
- Une **estimation des coûts** (déplacements, matériel, fournitures)

## Remise du document

Le document final, incluant une page titre, est remis :

- Au professeur-superviseur  
- À l’intervenant du milieu (s’il y a lieu)  
- En version électronique (Word ou PDF) au coordonnateur
