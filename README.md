# INF4173-Projet-Synthese

## Objectifs
Réaliser une synthèse des apprentissages qu'il a réalisés au cours de ses études en proposant des solutions pertinentes à une situation problématique.

## Contenu
Réalisation des différentes étapes menant à la solution d'un problème informatique dans des conditions se rapprochant de celles rencontrées dans le monde du travail :
+ problématique
+ analyse
+ conception
+ développement
+ implantation
+ évaluation
+ rédaction des documents techniques
+ présentation des résultats devant un auditoire.
